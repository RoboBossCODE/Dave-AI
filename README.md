# Dave AI V2 — static GitHub Pages chatbot

This is a fully offline-capable-after-loading, rule-based JavaScript chatbot. No backend, model, API, tracking or external assets. It does not provide generative AI or unrestricted natural-language understanding.

## Deploy
1. Create a GitHub repository (e.g. `dave-ai`).
2. Upload `index.html` to the repository root.
3. Open Settings → Pages → Build and deployment → Deploy from a branch.
4. Select `main` and `/(root)`, then Save.
5. Visit `https://YOUR-USERNAME.github.io/dave-ai/` once deployment completes.

## Features
- Keyword/topic matching and follow-up context
- Structured knowledge base with explanations and examples
- Safe arithmetic expression parser (no eval)
- Unit conversions, random dice and coin toss, text tools
- Local browser memory, history, export and reset
- Optional Web Speech API voice, responsive mobile layout

## Limitations
- Responses are assembled from curated knowledge and rules, not generated by a language model.
- Context is limited and topic matching can make mistakes.
- All saved data is local to that browser/device; clearing site data removes it.
- Voice depends on browser support.

## Extending Dave
Edit the `kb` array in `index.html` to add topics. Add custom intents to `respond(raw)` above the topic-matching section. Keep specific intents before broad ones.
